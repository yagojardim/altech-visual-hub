# Altech Visual Base

Quero construir a primeira base visual navegável da Plataforma Altech.

Use o Bootstrap Pack abaixo como referência obrigatória.

Não crie funcionalidades fora do escopo.

Não implemente Kanban, Sprint, IA, Billing, Portal Cliente, Snapshot ou Discovery agora.

Construa apenas:

- Login

- Workspace Shell

- Sidebar

- Topbar

- Breadcrumb

- Command Palette

- Dashboard inicial

- Board Container

- Project Overview

- Work Item base

- Estados de loading, empty, error e unauthorized

- Estrutura preparada para Supabase e Permission Driven UI

This project was built with [Lovable](https://lovable.dev).
